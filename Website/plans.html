읽기 계획

Reading Plans

한 계열의 논문을,
한눈에 차례대로.

One line of research.
In order, at a glance.

논문을 모아 차례와 날짜를 정하고, 발표 자료와 코드를 논문 옆에 붙여 둬요. 아래 창을 직접 누르고 끌어 봐도 돼요.

Gather the papers, give them an order and days to read them, and keep the slides and the code beside each one. The window below works — click it, drag in it.

표의 열

The table

줄마다 진짜 논문.
칸은 대부분 차 있어요.

Every row is a paper.
Most cells fill themselves.

Notion의 표와 다른 점은 줄이 진짜 논문이라는 거예요. 제목도, 진행도, 링크도 적지 않아도 차 있어요.

Unlike a blank table, each row here is a paper you already have. The title, the progress and the links are there before you type a thing.

저절로 채워지는 열

Filled in for you

  • 제목 · 저자 · 해 · 학회 — 서지에서
  • 진행 — 마지막으로 읽은 쪽에서
  • 논문 링크 — arXiv 번호와 DOI에서
  • 노트 · 표시 수, 더한 날, 마지막으로 읽은 날
  • Title, authors, year, venue — from the bibliography
  • Progress — from the last page you read
  • Paper link — from the arXiv number or the DOI
  • Notes and marks, date added, last read

내가 정하는 열

Yours to set

  • 읽을 날 — 적거나, 끌거나, 한 번에 나누거나
  • 자료 — 주소 붙여넣기, 파일 끌어다 놓기
  • 섹션과 차례 — 계획마다
  • 상태 · 태그 · 별점 — 지금 있는 그대로
  • Read on — type it, drag it, or spread a whole plan at once
  • Materials — paste a link, drop a file
  • Sections and order — per plan
  • Status, tags, rating — as they are today

보기

Views

  • 표 — 모든 선반에서 [목록 | 표]로 바꿔요
  • 달력 — 계획에서만. 다른 계획의 논문은 흐리게 겹쳐 보여요
  • 묶기 — 섹션 · 주 · 상태
  • 열 고르기 — 열 머리를 오른쪽 클릭, 눌러서 정렬
  • Table — every shelf switches between List and Table
  • Calendar — in a plan. Other plans’ papers show faintly
  • Group by — section, week or status
  • Columns — right-click a heading to choose; click to sort

저장

Storage

라이브러리 폴더 안의
작은 파일.

Small files,
in your library folder.

서버가 없어요. 폴더가 클라우드로 맞춰지면 맥과 윈도우·리눅스가 같은 계획을 봐요. 옛 버전은 이 파일들을 모른 채 지나가서 기록이 깨지지 않아요.

No server. When the folder syncs, Mac, Windows and Linux see the same plans. Older versions pass these files by, so the records they keep stay as they are.
