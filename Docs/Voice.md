# 말투 — 두 언어, 두 목소리

앱과 배포 페이지가 쓰는 말은 두 가지다. 한국어는 **토스**의 말투, 영어는 **애플**의 말투.
둘은 번역 관계가 아니라 **같은 것을 각자의 언어로 말하는 관계**다. 한 쪽을 직역하면
둘 다 어색해진다.

---

## 1. 한국어 — 토스

### 1.1 토스 말투를 뜯어보면

토스가 다른 한국 서비스와 갈리는 지점은 다섯 가지다.

**① 해요체. 합니다체도, 한다체도 아니다.**

| | |
|---|---|
| ✗ 합니다체 | 송금이 완료되었습니다. → 기업 공지 같다 |
| ✗ 한다체 | 송금했다. → 설명문 같다. 읽는 사람이 없다 |
| ✓ 해요체 | **보냈어요.** |

이게 가장 큰 표식이다. 높임말이지만 딱딱하지 않고, 사람이 사람에게 말하는 높이다.

**② 주어가 시스템이 아니라 사용자, 또는 결과다.**

시스템이 무엇을 했는지가 아니라 **무슨 일이 일어났는지**를 말한다.

| ✗ | ✓ |
|---|---|
| 파일이 저장되었습니다 | 저장했어요 |
| 오류가 발생했습니다 | 문제가 생겼어요 |
| 인증에 실패하였습니다 | 확인하지 못했어요 |

피동형(되었습니다, 처리됩니다)을 거의 쓰지 않는다.

**③ 쉬운 말. 한자어와 외래어를 우리말로 내린다.**

| ✗ | ✓ |
|---|---|
| 입력하세요 | 적어주세요 |
| 조회 | 확인 |
| 등록 | 추가 · 만들기 |
| 삭제 | 지우기 |
| 실행 | 열기 |
| 선택 | 고르기 |
| 이동 | 옮기기 |
| 검색 | 찾기 |

단, **뜻이 흐려지면 쉬운 말을 포기한다.** 토스도 '송금'은 송금이라고 쓴다.
이 앱에서는 논문·서지·인용·주석처럼 연구자가 매일 쓰는 말을 억지로 풀지 않는다.

**④ 한 문장에 한 가지. 짧게 끊고, 뜻으로 줄을 바꾼다.**

```
✗  라이브러리 폴더를 옮기려면 숨어 있는 .papertime 폴더까지 함께 옮겨야 하며
   PDF만 복사하면 새 라이브러리가 시작되고 노트는 남겨집니다.

✓  폴더를 옮길 때는 숨어 있는 .papertime까지 같이 옮겨주세요.
   PDF만 복사하면 노트가 따라오지 않아요.
```

**⑤ 문제가 생기면 탓하지 않고, 다음에 할 일을 알려준다.**

```
✗  잘못된 파일 형식입니다.
✓  이 PDF는 열 수 없어요. 파일이 깨졌을 수 있어요.
```

### 1.2 이 앱에서 지킬 것

- **설명·안내·빈 화면·오류: 해요체.** "~해요", "~예요", "~할 수 있어요", "~하면 돼요".
- **부탁할 때만 "~해주세요".** 남발하지 않는다. 명령이 아니라 안내면 그냥 "~하면 돼요".
- **단추와 메뉴는 짧은 명사형·동사형.** "보내기", "지우기", "폴더 고르기", "완료".
  단추에는 해요체를 붙이지 않는다 — "보내요"가 아니라 "보내기".
- **느낌표는 거의 쓰지 않는다.** 토스는 호들갑스럽지 않다. 따뜻하되 들뜨지 않는다.
- **"님", "고객님" 쓰지 않는다.** 이 앱에는 계정이 없다.
- **숫자를 먼저.** "3초", "13개", "0원"처럼 잴 수 있는 것을 앞에 둔다.

### 1.3 예외 — 한다체가 남는 자리

**배포 페이지의 선언 문장 한두 개**는 한다체를 쓸 수 있다. 제품을 설명하는 말이
아니라 제목에 가까운 말이기 때문이다.

```
논문을 읽는 곳과 글을 쓰는 곳 사이에, 아무것도 없다.
```

이건 표제다. 그 아래 설명하는 문장부터는 다시 해요체로 돌아온다.
이런 자리는 페이지 전체에서 **셋을 넘기지 않는다.**

## 2. 영어 — 애플

### 2.1 규칙

**① 능동태, 현재형, 짧은 평서문.**

| ✗ | ✓ |
|---|---|
| The file has been saved. | Saved. |
| An error was encountered. | Paper Time can't open this PDF. |
| Marks will be written into the PDF. | Marks live in the PDF. |

**② 기능을 자랑하지 않는다. 기능을 말하면 그게 자랑이다.**

금지어: *powerful, seamless(ly), simply, just, easy, revolutionary, amazing,
unleash, supercharge, leverage, utilize, robust, cutting-edge*.

```
✗  Paper Time's powerful annotation engine seamlessly syncs your highlights.
✓  Highlights are written into the PDF. Any reader can see them.
```

**③ 구체적인 명사와 센 동사.** 추상명사를 피한다.

```
✗  Enhanced cross-platform compatibility
✓  The same folder opens on macOS, Windows and Linux.
```

**④ 리듬. 조각 문장과 3박자를 쓴다.**

```
Read. Mark. Write.
One folder. Every desktop.
```

**⑤ 대소문자는 macOS HIG를 따른다.**
- 메뉴·단추·기능 이름: **Title Case** — "Add Papers", "Export BibTeX", "Sync Now".
- 문장·설명·빈 화면: **Sentence case** — "No papers here yet."

**⑥ 오류는 무슨 일인지와 다음에 할 일을 말한다. 사과하지 않는다.**

```
✗  Sorry! Something went wrong.
✓  Paper Time can't read this file. It may be damaged.
```

**⑦ "you"를 아껴 쓴다.** 명령형이나 사물을 주어로 두는 편이 더 애플답다.

```
△  You can draw on the page with your pen.
✓  Draw on the page. The marks land in the file.
```

### 2.2 한국어를 직역하지 않는다

해요체의 따뜻함은 영어에서 "please"와 느낌표로 번역되지 않는다.
애플의 대응물은 **간결함과 자신감**이다.

| 한국어 (토스) | ✗ 직역 | ✓ 영어 (애플) |
|---|---|---|
| 저장했어요 | It has been saved for you! | Saved. |
| 문제가 생겼어요 | A problem has occurred | Something didn't work. |
| 폴더를 고르면 돼요 | You just need to choose a folder | Choose a folder. |
| 아직 아무것도 없어요 | There is nothing here yet | Nothing here yet. |

## 3. 짝지어 보기

실제로 이 앱에 들어가는 문장들.

| 자리 | 한국어 | English |
|---|---|---|
| 빈 서가 | 아직 논문이 없어요. PDF를 끌어다 놓아보세요. | No papers yet. Drag in a PDF. |
| 저장 충돌 | 다른 기기에서 먼저 바뀌었어요. 둘 다 두고 갈까요? | This changed on another device. Keep both? |
| 서지 확인 | 이 값은 확실하지 않아요. 한번 봐주세요. | Not sure about this one. Take a look. |
| 피드백 보내기 | 보내기 | Send |
| 피드백 안내 | 화면은 이미 찍어뒀어요. 위에 바로 그려도 돼요. | The screenshot is already here. Draw on it. |
| 이름 칸 | 여기 적은 이름으로 기록에 올라가요 | This is the name that goes on the list |
| 고침 | 고쳤어요 | Fixed |
| 크래시 뒤 | 지난번에 갑자기 닫혔어요. 무슨 일이었는지 한 줄만 알려주실래요? | Paper Time quit unexpectedly. What were you doing? |

## 4. 고칠 때 확인하는 것

1. 한국어에 **합니다체·한다체가 남았는가** (표제 예외 말고).
2. 한국어에 **피동형**이 남았는가 — "되었어요", "처리돼요".
3. 영어에 **금지어**가 있는가 — powerful, seamless, simply, just, easy.
4. 영어가 한국어의 **직역**인가 — 두 문장의 길이가 비슷하면 대개 직역이다.
5. 단추에 **해요체**가 붙었는가 — "보내요" ✗ / "보내기" ✓.
6. 느낌표를 썼는가 — 거의 언제나 빼는 게 낫다.
