# 1.0을 향한 기능 결정 (2026-11-02, 0.9.37 기준)

정식 배포 전에 무엇을 남기고 무엇을 레거시로 돌릴지 사용자가 `Website/features.html`에서 고른 결과 그대로다.
«레거시»는 코드와 파일 호환은 두되 메뉴·설정·설명서·페이지에서 내리는 것을 뜻한다(정확한 뜻은 아래 «레거시의 뜻»).
별은 강조하고 싶은 정도다.

## 레거시의 뜻

- 파일은 계속 읽히고 써진다(다른 기기·옛 버전과 호환).
- 만드는 UI(메뉴·단추·설정 절·단축키)는 내린다. 설명서·배포 페이지·앱 안 기능 소개에서도 내린다.
- 코드는 남긴다. 2.0에서 다시 꺼낼 것(지도·초안·공명, 그래프, 아이패드)이 있어서다.

  - 지금 있는 양식도 좋은데, 각 학회들마다 혹은 각 저널들마다의 스타일도 추가하면 좋긴 하겠다.
