# What Ultracopy is held to: formulas a paper writes, one per line, in the
# LaTeX an author types. `make.sh` sets each inline and displayed, in every
# font setup, one page each; `ultracopy-bench.swift` reads the pages back and
# compares what it reads with this, structurally (`x_{i}` is `x_i`, `x_{ij}`
# is not `x_ij`). A line of the form `source => expected` says what a reading
# of the page can be asked for when it cannot be the source itself: readings
# separated by ` || `, `=` for the source, `-` for nothing, and `setup: …` for
# a reading allowed in the setups named only — where the page draws something
# else: mathptmx has no bold maths, unicode-math's \boldsymbol draws the
# plain letter, and TeX Gyre Termes Math sets \binom's halves as far apart as
# the lines of a two-line pmatrix, which then draws the same.
#
